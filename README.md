# Taller de Recursividad

**Estudiante:** Juan Andres Checa Sol

## Descripción

Taller de la materia Estructuras de Datos Lineales sobre recursividad en Java. Contiene 14 ejercicios, cada uno resuelto con una función recursiva (caso base y llamada recursiva) y guardado en su propia clase dentro de la carpeta `src/Recursividad`.

Los ejercicios son:

1. Factorial de un número
2. Invertir un número
3. Sumatoria 1 + 1/2 + 1/3 + ... + 1/n
4. Suma de los dígitos de un número
5. Sumatoria hasta el número leído
6. Potencia (base elevada al exponente)
7. Máximo común divisor con el algoritmo de Euclides
8. Copiar una cadena en otra
9. Cociente de la división entera con restas sucesivas
10. Multiplicación con sumas sucesivas
11. Suma de los elementos de un arreglo
12. Suma de los elementos de una matriz de tamaño m x n
13. Serie de Fibonacci hasta un límite
14. Función de Ackermann

## Instrucciones para ejecutar

1. Clonar el repositorio: `git clone https://github.com/andres-checa/Taller-Recursividad`
2. Abrir el proyecto en NetBeans o VS Code
3. Compilar y ejecutar cada clase de forma individual desde la carpeta correspondiente:
   1. Ubicarse en la carpeta donde se clonó el repositorio
   2. Utilizar el siguiente comando: `java src/Recursividad/<NombreArchivo>.java`

Ejemplo: `java src/Recursividad/Ejercicio1.java`
